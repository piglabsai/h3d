# Changelog

## 0.1.1

- Link the PyPI project metadata and package README to the hosted Sphinx
  documentation.

## 0.1.0

- Initial preview of voxel indexing with independent H3 and vertical resolutions.
- Version-1 128-bit voxel format with WGS84 ellipsoidal height, hierarchical
  operations, and lazy altitude range traversal.
- WGS84 geodetic and ECEF conversions.
- Two-word storage helpers and a verified DuckDB-to-Parquet example.
